# Admin Demo Script

## Natural Spoken Version

"Good day. For this part of the demonstration, I will focus on the admin side of the system. The admin serves as the main overseer of the platform and is responsible for managing the data and settings that support the daily operations of the agriculture office."

"After logging in, the admin can access the dashboard or reports page. This gives a quick overview of the system and helps monitor records and transactions. It allows the admin to see the bigger picture of what is happening in the office."

"The admin can also manage barangays and associations. This is important because farmer records are organized based on these locations and groupings. By maintaining this master data, the admin helps keep the whole system accurate and well-structured."

"Another important function of the admin is fee schedule management. The admin can update the fees used by the system for membership, annual dues, and other related charges. This ensures that the correct amounts are applied during processing."

"The admin is also responsible for user management. This means the admin can create and manage office accounts and make sure that access is given only to authorized users. In this way, the admin helps maintain both organization and security inside the system."

"Overall, the admin side is focused on oversight, configuration, and control. While staff members handle the daily transactions, the admin makes sure the system is properly managed, updated, and ready to support the services provided to farmers."

## Click-by-Click Demo Flow

### 1. Login

- Open the system login page.
- Enter `admin@anitech.test`.
- Enter `password123`.
- Click `Login`.

Say:

"For this part of the demonstration, I am logged in as the admin. The admin is responsible for overseeing the system and managing the core settings and records used by the agriculture office."

### 2. Dashboard / Reports

- After login, wait for the `Reports` or dashboard page to load.
- Briefly point to the summary cards, charts, or report overview on the page.

Say:

"This is the admin dashboard or reports page. It gives the admin a quick overview of records and transactions in the system, which helps in monitoring the overall performance of the office."

### 3. Location Management: Barangays

- On the left sidebar, click `Location Management`.
- Click `Barangays`.
- Show the list of barangays.
- If needed, click `Create` or open one barangay record.

Say:

"From Location Management, the admin can manage barangays. This is important because farmer records are organized according to these locations, so keeping this data updated helps maintain accuracy throughout the system."

### 4. Location Management: Associations

- Stay under `Location Management`.
- Click `Associations`.
- Show the list of associations.
- If needed, open one association record.

Say:

"The admin can also manage associations. Since farmers may belong to specific associations, this part helps keep the grouping of farmer records complete and organized."

### 5. Fee Configuration

- On the left sidebar, click `Fee Configuration`.
- Click `Fee Schedules`.
- Show the list of fee schedules.
- If there is an active schedule, point to it.
- If appropriate, open `Create` or `Edit` without saving changes.

Say:

"Next is Fee Configuration. Here, the admin manages the fee schedules used by the system, such as membership fees, annual dues, and related charges. This ensures that the correct amounts are applied during transactions and processing."

### 6. User Management

- On the left sidebar, click `User Management`.
- Click `User Accounts`.
- Show the list of office users.
- If needed, open a sample user account or the create user form.

Say:

"In User Management, the admin can create and manage office accounts. This allows the admin to control who can access the system and what role each user has, which helps maintain both security and proper workflow management."

### 7. Optional: Notifications

- Click the notification bell in the sidebar footer if visible.
- Show the notifications page.

Say:

"The admin can also check notifications for important updates inside the system, which helps with monitoring recent activity and system events."

### 8. Closing

- Return to the main dashboard if needed.

Say:

"Overall, the admin side focuses on oversight, configuration, and control. The admin does not mainly process daily transactions, but instead makes sure the system is organized, updated, secure, and ready to support the work of the agriculture office."

## Optional Closing Line

"In summary, the admin plays a key role in making sure the system remains organized, secure, and reliable for the entire agriculture office."
